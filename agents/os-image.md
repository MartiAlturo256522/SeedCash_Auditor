# OS lane

Own the `os` rows in `brain/invariants.md`. Read the OS tree the operator passed. If no OS root was passed, return zero findings and say the lane was skipped.

`INV-KERNEL-NET` is about the fragment text. `INV-IMAGE-NET` is about a built config. Do not close one because the other looks fine. Do not file these against the app repo; `file_ready` on the finding stays false unless the operator passed an OS repo.

Four findings maximum.
